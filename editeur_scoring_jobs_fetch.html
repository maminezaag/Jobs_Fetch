À propos de Git / GitLab / CI/CD : ils sont séparés dans la version de départ : Git = 3 points, GitLab = 0, CI/CD = 0. Ces derniers ne sont pas exclus, mais ils n'ajoutent aucun point. La détection du script repose sur des sous-chaînes : les tests sont indicatifs.
